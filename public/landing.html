THE APEX COUNCIL

Four agents. One decision record.

APEX does not ask one model to be optimistic, skeptical, and safe at the same time. Each role has a job, a boundary, and a visible handoff.

B01 · THESIS

Bull

Builds the strongest supported case for the setup using only evidence in the packet.

“What could go right?”
B02 · CHALLENGE

Bear

Receives the same facts and looks for invalidation, fragility, crowded positioning, and missing data.

“What breaks the thesis?”
R03 · CONSTITUTION

Referee

Runs deterministic portfolio checks for leverage, concentration, loss, size, and liquidation distance.

“Does it pass the rules?”
G04 · FIREWALL

Guardian

Checks freshness, authority, duplicate risk, and policy. It fails closed when execution cannot be verified.

“Is it safe to hand off?”
